# Codex image job: concept pictures for the 22 new town buildings and the toy monorail (2026-10-15)

The game is a paper-plane dogfight over a toy city on a classroom rug. Every building is a giant classroom object
turned into a building. Look first at:
- `assets/references/classroom-city-approved-v1.png`: the game's look (cardboard, books, toy bricks, bright
  red/blue/yellow/green on warm kraft, chunky and readable).
- Our existing concept pictures, which the new ones must sit beside as one family: `assets/models/sweet-shop/concept-front.png`,
  `assets/models/gateway-towers/concept-front.png`, `assets/models/glue-tower/concept-front.png`,
  `assets/models/milk-carton-tower/concept-front.png`, `assets/models/pencil-cup-tower/concept-front.png`.
  Same framing: one building alone, centred with margin, 3/4 front view from slightly above, plain light-grey studio
  background, soft even light, no harsh shadows, a little toy-brick doorstep, windows with frames, a door.

## Pictures to make (square, at least 1024 x 1024), one per building
Save each as `assets/models/<name>/concept-front.png` (make the folder). Sizes are studs, width x depth x height; keep
the proportions. A paper plane is 7 studs wide, so a 40-stud hole is big. Fly-through holes must be open, clean and
clearly see-through (we must see the grey background through them), never filled with glass, bars or ropes.

BATCH = see the job's own line: "batch 1" makes rows 1-11, "batch 2" makes rows 12-22 plus the monorail.
