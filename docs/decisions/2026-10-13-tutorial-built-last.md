# The tutorial is built last

**Decided:** 2026-10-13 (Alan, D12)  
**Status:** in force

## Decision
The full tutorial is built last (before Stage 11), once planes, weapons, hangar and HUD won't change. It lives in its own empty copy of the classroom. Practice mode lives in the tutorial. Stage 6 keeps only the HUD and menu work.

## Why
A tutorial built earlier would have to be redone every time those things change.
