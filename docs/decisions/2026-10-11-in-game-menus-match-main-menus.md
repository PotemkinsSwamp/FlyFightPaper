# In-game menus reuse the main menu's art

**Decided:** 2026-10-11 (Alan)  
**Status:** in force

## Decision
An in-game version of a menu (like the quick hangar) looks like its out-of-game screen: same pieces, same style, floating over the live game. No new art set unless Alan asks.

## Why
You are still in the match; a different style made it feel like a separate game.
